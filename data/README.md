# Data preparation

Scripts only. Keep raw images, crops and manifests with private data outside the repo.

Required protocol: NFC labels; perspective warp from four-point polygons; about 10%
vertical margin; exclude `###`; 32x128 resize. Image-level split, fixed validation seed,
near-duplicate groups in the same split, training-only rare statistics, frozen subsets.

The adapters below are explicit scaffolds until the real VinText annotation format is
verified. No dataset or synthetic vocabulary is generated by repository initialization.
